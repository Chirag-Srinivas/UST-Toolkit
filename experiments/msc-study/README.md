# Frozen MSc study

Author: Chirag Srinivas. Snapshot prepared: 10 September 2026.

**Definitive evidence:** `IRP_RESULTS_FINAL`, including S1–S9 and
`T1_S1_background5000_seed4711`.

**Historical material:** `IRP_RESULTS_NEW` and `IRP_results`. These are retained
for provenance and must not be combined with the definitive results as if they
were one experimental design. Failed attempts and superseded runs retain their
original labels and locations.

The full archive preserves original file bytes and relative folder structure,
including source snapshots, input snapshots, output files, analyses and reports.
It includes the current modified Java runtime and source, with the provenance
limitations described in `lib/MATSim/MODIFICATIONS.md`.

The T1 standalone dashboard is a later presentation export of saved results.
It is not evidence that the simulation was rerun on the snapshot date.

Use the complete MSc research ZIP linked from the matching GitHub release.
The large ZIP is not stored in Git history. Its `SNAPSHOT_MANIFEST.json` records
individual file hashes and classifications. The release provides archive hashes.

Some historical configuration/log files contain original local machine paths.
Preserving those files is intentional. To rerun on another machine, work from
a copy and adapt paths; never edit the frozen evidence in place. Reproduction
of every historical run has not been newly tested.

Publication of input networks and third-party data requires confirmed source
and redistribution terms; local archive preparation does not establish those.
