# MATSim-UAM runtime

The source repository contains the modified Java source in `MATSim/`.
The fresh toolkit ZIP additionally includes `matsim-uam-5.0.0.jar` here.
The binary is excluded from Git history. To use a source checkout, obtain it
from the toolkit release ZIP, or build from `MATSim/pom.xml` with Java 21 and
Maven. Check `MATSim/PROVENANCE.json` for its expected hash and audit limits.

This is a modified research variant, not stock MATSim-UAM. Its original licence,
attribution, modification notes and build declaration are supplied together.
